"How long the model took to answer" — Measured wall-clock time in milliseconds from question submission to full answer generation. Reports total time including context retrieval and model inference.

🎯 Accuracy

"Factual adherence to verified rules" — Calculated only when an official university policy reference answer is available in our dataset. If no reference is available, explicitly displayed as 'Accuracy not verified – no suitable reference answer available'.

"Claims not supported by evidence" — Checks whether fee amounts, attendance percentages, dates, and names exist in official retrieved university context or contradict policy.

Quality vs Latency Pareto Frontier (Exercise 4)
Key Finding: Qwen 2.5 0.5B achieves 232ms latency with 57.3% accuracy, while Qwen 2.5 1.5B achieves 72.3% accuracy at 608ms. This represents a classic Pareto frontier where higher reasoning requires a 2.6x latency tradeoff.
Multi-Dimensional Trade-off Radar (Exercises 1 & 3)
Key Finding: Visualizes Accuracy, Relevance, Hallucination Resistance, Latency Efficiency, and RAM Efficiency. Qwen 0.5B dominates on efficiency metrics, whereas Qwen 1.5B dominates on qualitative reasoning.
RAM, Disk Image & CPU Utilization (Exercise 3)
Key Finding: Qwen 2.5 0.5B uses 580MB RAM (34% CPU) fitting inside AWS Free-Tier 1GB instances. In contrast, Qwen 1.5B requires 1,420MB RAM (78% CPU) and requires 2GB+ instances.
Accuracy Breakdown Across Knowledge Base Domains (Exercise 2)
Key Finding: All models achieve >75% on Examination and Attendance queries due to high chunk lexical density, while codebase architecture questions show higher variance between 0.5B (60%) and 1.5B (100%).
